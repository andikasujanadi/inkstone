# Contributing to Inkstone

Inkstone is in early development. Bug reports should include the app version, device, Android version, stylus model and steps to reproduce. Small sample files or a screen recording are useful when a problem depends on an artwork.

Before opening a substantial code contribution, discuss the proposed change in an issue. Keep changes focused, preserve existing artwork compatibility, add regression coverage for behavior changes, and run the relevant Android and Rust checks.

Read [LICENSE](LICENSE), [additional artwork permissions](ADDITIONAL_PERMISSIONS.md), and the [licensing history](docs/LICENSING.md). Preserve contributor attribution and all third-party notices. Contribution credit is not copyright assignment.
